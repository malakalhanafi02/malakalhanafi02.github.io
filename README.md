# Malak Al-Hanafi — Engineering Portfolio

Personal portfolio of robotics, applied AI, biomedical engineering, research, and teaching.

## Development

Use Node.js 22 or newer. Run `npm ci`, then `npm run dev`.

`npm run build` exports every page to `out/` for GitHub Pages. The repository is intended for the root site at https://malakalhanafi02.github.io/.

## Content

Project descriptions live in `lib/projects.json`. Teaching materials, credentials, photographs, and report figures are under `public/`. Each project has its own directly accessible static page.

The mower demonstration runs the original trained segmentation model locally in the visitor's browser. Uploaded images stay on the visitor's device.
